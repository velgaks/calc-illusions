# Україна у даних: доходи та умови життя українців

Скільки заробляють українці, де й ким працюють, у яких умовах живуть? Цей некомерційний дашборд допомагає знайти відповіді в даних **Socio-Economic Status of Households Survey (SESH)**. Обстеження охоплює 18 837 людей і 8 023 домогосподарства на підконтрольній території України. Польовий етап тривав із грудня 2023 до лютого 2024 року.

- Огляд: чотири редакційні сюжети про демографію, доходи, зайнятість і матеріальні умови.
- Конструктор: показник, один необов'язковий розріз, кілька фільтрів, числовий поріг, відтворюваний URL і CSV агрегатів.
- Дві окремі одиниці аналізу: 18 837 людей і 8 023 домогосподарства. Ваги та знаменники не змішуються.
- Український та англійський інтерфейс.

Live: https://velgaks.github.io/calc-illusions/

## Швидкий старт

```bash
cd web
npm install
npm run dev
```

Vite читає статичні файли з кореневого `public/`. Детальний `people.json` або `households.json` завантажується лише після відкриття конструктора; головна використовує малий `overview.json`.

## Відтворення даних

Покладіть дві оригінальні книги SESH у `data/raw/` під їхніми вихідними назвами, потім:

```bash
python -m pip install -r prep/requirements.txt
python prep/build_sesh.py
python prep/build_sesh.py --check
```

Пайплайн потоково читає `.xlsx`, перевіряє 18 837 / 8 023 записів, ваги й ключі, замінює `KEY_QUEST` на послідовний cluster ID та не експортує контакти, відкриті тексти, райони чи точні локації.

Вихідні файли:

- `public/data/overview.json` — готові агрегати огляду;
- `public/data/people.json` — columnar/dictionary-coded масив людей;
- `public/data/households.json` — масив домогосподарств;
- `public/data/metadata.json` — реєстр змінних, universe, категорії, джерело й ліцензія.
